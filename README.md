  Локальная PWA для готовки из продуктов, которые уже есть в холодильнике.<br />
  Работает офлайн после первой загрузки, без авторизации — все данные хранятся на устройстве.
</p>

---

## Возможности

- Добавление ингредиентов в «холодильник» с подсказками
- Подбор рецептов по совпадению ингредиентов
- Случайный рецепт одним нажатием
- Карточка рецепта с пересчётом порций
- Режим готовки с Wake Lock (экран не гаснет)
- Избранное и недавние рецепты
- Установка как PWA на телефон или компьютер

## Запуск

```bash
bun install
bun run dev
```

Откройте [http://localhost:3000](http://localhost:3000).
